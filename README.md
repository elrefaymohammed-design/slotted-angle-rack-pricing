# Slotline — slotted-angle rack pricing

A no-build, responsive web calculator. Open `index.html` in a browser; no dependencies or server are required.

## Rack rules
- Height 500–6,000 mm in 50 mm increments; bay width 500–1,200 mm in 50 mm increments with manual sizes; depth 300–1,200 mm in 50 mm increments.
- Four ST37 steel uprights per bay: 40 × 40 × 1.5 mm, 76 mm flat pattern, priced per upright.
- SA shelf thickness: 0.7, 0.8, 0.9, 1.0, 1.2, 1.5, or 2.0 mm. Shelf flat pattern is bay width + 90 mm by bay depth + 90 mm.
- Choose shelf connection: **slotted-web bolted connection** or **SA shelf with Euro hooks**. Euro-hook mode counts four hooks per shelf, with editable unit price. Bolted mode counts 8 webs per web level; first and last levels use webs, with a middle web level at rack height >= 2,500 mm. Each web level uses 24 M8 × 20 mm bolt-and-nut sets; other shelf levels use 8 sets.
- Omega reinforcement is optional. When selected, choose 1, 2, or 3 omegas per shelf and 0.7 or 0.8 mm thickness. Omega flat pattern is 130 mm; length is bay width − 10 mm. Optional omegas appear in the shelf description and quote.
- Editable prices for uprights, SA shelves, webs, hooks, omegas, fasteners, labor, and markup. Currency options USD, EUR, GBP, EGP, SAR.

All unit prices default to zero. Set your rates before quoting. Print/save the quote as PDF from the browser.
